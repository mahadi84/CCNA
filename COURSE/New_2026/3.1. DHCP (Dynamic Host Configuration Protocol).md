## 1. What is DHCP?

**DHCP = Dynamic Host Configuration Protocol.**

DHCP is a network protocol that automatically provides IP configuration to devices without manually entering every setting.

**Simple Explanation:** DHCP automatically assigns IP addresses and other network settings to computers when they connect to a network.

### Real-Life Analogy: Bank Employee ID Card

Imagine a new employee joins the Treasury department.

| Banking Example | DHCP Concept |
|---|---|
| HR Department | DHCP Server |
| New Employee | DHCP Client |
| Employee ID | IP Address |
| Department Information | Network Configuration |
| ID Validity Period | DHCP Lease Time |

Just as HR assigns an employee an ID, DHCP assigns a device an IP address.

**Remember:** DHCP = Automatic IP Configuration.

---

## 2. Why Do We Need DHCP?

Suppose a bank has 200 computers.

**Without DHCP:**
- The administrator manually configures IP addresses on all 200 computers.
- Configuration takes more time.
- Manual mistakes may cause duplicate IP addresses.
- Network management becomes difficult.

**With DHCP:**
- Computers receive IP addresses automatically.
- Saves time and administrative effort.
- Reduces manual configuration errors.
- Makes large network management easier.
- Supports automatic IP lease management.

| Without DHCP | With DHCP |
|---|---|
| Manual IP assignment | Automatic IP assignment |
| Time-consuming | Saves time |
| More manual errors | Fewer manual errors |
| Difficult to manage | Easier centralized management |

**Memory Trick:** DHCP = Automatic IP Assignment.

## 3. What Information Does DHCP Provide?

Imagine a Treasury computer connects to the bank's network.

### Example DHCP Configuration

| Network Setting | Example Value |
|---|---|
| IP Address | `192.168.10.100` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.10.1` |
| DNS Server | `192.168.10.2` |
| Lease Time | 24 Hours (Example) |

### Meaning of Each Setting

1. **IP Address:** Identifies the computer on the network.
2. **Subnet Mask:** Identifies the network and host portions.
3. **Default Gateway:** Allows communication with other networks.
4. **DNS Server:** Converts domain names into IP addresses.
5. **Lease Time:** Defines how long the DHCP client may use the assigned IP configuration.

**Important:** DHCP provides network settings, but it does not automatically guarantee internet connectivity. Routing, DNS and other services must also work correctly.

## 4. How Does DHCP Work? — DORA

**DORA = Discover → Offer → Request → Acknowledgment**

DORA is the four-step process used during normal initial DHCP address allocation.

### DHCP DORA Process

```text
       DHCP CLIENT                    DHCP SERVER
            |                              |
            |------ 1. DISCOVER ---------->|
            |                              |
            |<------- 2. OFFER ------------|
            |                              |
            |------ 3. REQUEST ----------->|
            |                              |
            |<------- 4. ACK ---------------|
            |                              |
         IP CONFIGURATION COMPLETED
```

### Step 1 — Discover (D)

The computer starts without an assigned IP address.

It broadcasts a DHCP Discover message asking:

"Is there any DHCP server available?"

**Important Details:**
- Sender: DHCP Client
- Receiver: DHCP Server(s)
- Source IP: `0.0.0.0`
- Destination IP: `255.255.255.255`
- Source UDP Port: 68
- Destination UDP Port: 67

### Step 2 — Offer (O)

The DHCP server responds with an IP address offer.

Example:

"I can offer you IP address `192.168.10.100`."

The server also provides proposed network configuration and lease information.

**Important:** An offer is not yet a completed lease.

### Step 3 — Request (R)

The computer requests the offered IP address.

"I want to use `192.168.10.100` from this DHCP server."

During initial address selection, this message is normally broadcast so other DHCP servers know which offer was selected.

### Step 4 — Acknowledgment (A)

The DHCP server confirms the lease using a DHCPACK message.

"Approved! You can use this IP address."

The computer configures its approved network settings.

**Important:** DHCP replies may be broadcast or unicast depending on the client's state and DHCP message conditions.

### DORA Quick Revision

| Step | Message | Meaning |
|---|---|---|
| 1 | Discover | Client searches for DHCP server |
| 2 | Offer | Server offers an IP address |
| 3 | Request | Client requests the offered IP |
| 4 | ACK | Server confirms the assignment |

**Memory Trick:**

- Discover = Find a server.
- Offer = Server offers an IP.
- Request = Client requests the IP.
- ACK = Server approves the IP.

## 5. Important DHCP Technical Facts

| Topic | Remember |
|---|---|
| Full Form | Dynamic Host Configuration Protocol |
| Protocol | DHCPv4 |
| Transport Protocol | UDP |
| DHCP Server Port | 67 |
| DHCP Client Port | 68 |
| IP Assignment | Automatic |
| Process | DORA |
| IP Validity | Lease Time |
| Standard | RFC 2131 |

### Important UDP Ports

| Port | Used By |
|---|---|
| UDP 67 | DHCP Server |
| UDP 68 | DHCP Client |

**Memory Trick:** Server = 67, Client = 68.

### DHCP Lease Time

Lease time determines how long a client can use an assigned IP configuration.

Example:

- DHCP assigns `192.168.10.100`.
- Lease duration = 24 hours.
- Client periodically renews its lease.
- If the lease is not renewed, the address may eventually return to the available pool.

**Important:** DHCP clients normally attempt lease renewal before the lease expires.

## 6. Three Important DHCP Roles

### 1. DHCP Client

Requests an IP address and network configuration.

Example: Treasury department computer.

### 2. DHCP Server

Provides IP addresses and other network settings.

Example: A configured Cisco router or dedicated DHCP server.

### 3. DHCP Relay Agent

Forwards DHCP messages between different networks when the DHCP server is located in another subnet.

**Why is DHCP Relay Needed?**

DHCP Discover messages are initially broadcast. Routers normally do not forward ordinary broadcasts between different networks.

A DHCP Relay Agent forwards the client's DHCP request to a remote DHCP server.

**Cisco Command:**

`ip helper-address 192.168.1.10`

This command is configured on the router interface or Layer 3 SVI facing the client network.

Here, `192.168.1.10` is the remote DHCP server's IP address.

**Remember:**
- Same subnet = Client can reach a local DHCP server through the LAN.
- Different subnet = DHCP Relay may be required.

## 7. DHCP vs Static IP

| DHCP | Static IP |
|---|---|
| Assigned automatically | Configured manually |
| Uses lease time | No DHCP lease |
| Common for employee PCs | Common for network infrastructure |
| Easier centralized administration | Predictable fixed configuration |
| Reduces manual work | Requires manual management |

**Banking Example:**

- Employee computers → DHCP.
- Routers and switches → Usually static management addresses.
- Important servers → Static IP or DHCP reservation.

**Note:** DHCP reservations provide predictable addresses to selected devices based on identifiers such as their MAC address.
